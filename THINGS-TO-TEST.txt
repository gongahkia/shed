     Verify: file tree appears; terminal and Git operate against this folder.

  2. Test fast navigation: press Cmd-P, type AppCoordinator.swift, open it. Then Ctrl-G, enter a line
     number.
     Verify: file picker and jump-to-line are immediate.

  3. Test search: press Cmd-F, search makeCommandRegistry, then Cmd-G. Press Cmd-Shift-F and search the
     whole project.
     Verify: in-file and project search return useful locations.

  4. Test editing without saving: select a word, type any text, then Cmd-Z / Cmd-Shift-Z. Press Cmd-D to
     add the next matching selection; press Esc when done.
     Verify: cursor, multi-selection, undo, and rendering feel responsive.

  5. Test panes: press Cmd-\ to split, open another file with Cmd-P, switch focus with Cmd-Opt-←/→, then
     close the extra pane with Cmd-W.
     Verify: splits feel lightweight and preserve context.

  6. Test the integrated terminal: press Cmd-J; run pwd, git status --short, and swift --version.
     Verify: it opens as a bottom panel and uses the workspace directory.
