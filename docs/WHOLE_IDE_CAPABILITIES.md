# Whole-IDE capability inventory — Track B0

This inventory describes actual production routes and their test boundaries at the B0 entry revision. “Implemented” does not mean every platform, provider or user workflow is qualified. Full results and priorities are in [WHOLE_IDE_AUDIT.md](WHOLE_IDE_AUDIT.md). Class/source references below were checked for existence; runtime evidence is stated separately, never inferred from a name or dependency.

Production references are under `src/main/java/shed/`; tests under `src/test/java/shed/`. The accompanying evidence JSON is machine-readable.
