Itsy for Mac

Itsy is a native, focused code editor for macOS.

→ Get Itsy from GitHub

→ Build Itsy locally

Itsy offers a focused editor...

  • A native AppKit shell and Metal text view
  • Split panes, compact tabs, file tree, and terminal
  • Tree-sitter syntax highlighting and themes
  • Git status, diffs, commits, branches, and stash workflows
  • Plain, Vim, and Emacs keymaps
  • Low-overhead workspace indexing and no telemetry

...thoughtful navigation...

  • Project find, symbols, outline, and go-to-definition
  • Multiple selections and responsive undo/redo
  • Workspace state restored without opening an unwanted document
  • Gitignore-aware search, including .itsy/ workspace state

...and native developer support.

  • Lazy language-server sessions, diagnostics, completion, hover, and references
  • Debug launch, call stack, variables, watches, and console
  • Configurable JSON settings and workspace-local state
  • Unsigned local builds today; signing and notarization are tracked openly

Build Itsy

scripts/bootstrap.sh
swift build -c release
bench/scripts/make_app.sh
open Itsy.app

Itsy is pre-release. Release status and prerequisites are documented in the repo.
